# Tesla Model 3 landing page

Next.js App Router, TypeScript, and Tailwind CSS 4 implementation of the Tesla landing page.

## Run locally

Install Node.js 20.9 or newer, then run:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Commands

```bash
npm run dev
npm run typecheck
npm run build
npm run start
```
